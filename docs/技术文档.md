# 电动自行车车牌识别系统 - 技术文档

## 1. 项目概述

本项目实现基于传统计算机视觉算法的电动自行车车牌识别系统，**不使用任何深度学习或机器学习模型**。

### 1.1 技术栈
- Python 3.8+
- OpenCV (opencv-python)
- NumPy
- Matplotlib

### 1.2 系统架构

```
输入图像 → 预处理 → 车牌定位 → 畸变校正 → 字符分割 → 字符识别 → 输出结果
```

## 2. 已实现模块

### 2.1 图像预处理模块 (`ImagePreprocessor`)

**文件位置**: `src/image_process.py`

#### 2.1.1 功能说明

对输入图像进行标准化处理，增强图像质量，为后续处理提供更好的输入。

#### 2.1.2 处理流程

| 步骤 | 方法 | 说明 |
|------|------|------|
| 1 | 灰度化 | `cv2.cvtColor(BGR2GRAY)` 转换为单通道 |
| 2 | 高斯滤波 | `cv2.GaussianBlur` 去除高频噪声 |
| 3 | 直方图均衡化 | `cv2.createCLAHE` 增强对比度 |

#### 2.1.3 关键参数 (`config.py`)

```python
GAUSSIAN_KERNEL_SIZE = (5, 5)  # 高斯核大小

CLAHE_TILE_SIZE = (8, 8)       # CLAHE分块大小
```

#### 2.1.4 调用示例

```python

original, processed = preprocess_image("path/to/image.jpg")
```

### 2.2 车牌定位模块 (`PlateLocator`)

**文件位置**: `src/image_process.py`

#### 2.2.1 功能说明

在图像中定位车牌区域，返回候选车牌的位置和评分。

#### 2.2.2 定位方法

系统采用**三种互补的定位方法**，综合使用以提高检出率：

##### 方法一：颜色定位 (HSV)

```python
def color_locate(self, image):
    # 在HSV空间提取特定颜色区域
    white_mask = cv2.inRange(hsv, WHITE_LOWER, WHITE_UPPER)
    blue_mask = cv2.inRange(hsv, BLUE_LOWER, BLUE_UPPER)
    yellow_mask = cv2.inRange(hsv, YELLOW_LOWER, YELLOW_UPPER)
    green_mask = cv2.inRange(hsv, GREEN_LOWER, GREEN_UPPER)
```

**支持的车牌颜色**:
| 颜色 | HSV下界 | HSV上界 |
|------|---------|---------|
| 白色 | (0, 0, 200) | (180, 50, 255) |
| 蓝色 | (100, 50, 50) | (130, 255, 255) |
| 黄色 | (15, 50, 50) | (35, 255, 255) |
| 绿色 | (35, 50, 50) | (85, 255, 255) |

##### 方法二：边缘定位 (Sobel)

```python
def edge_locate(self, image):
    # Sobel垂直边缘检测
    sobel_x = cv2.Sobel(blurred, cv2.CV_64F, 1, 0, ksize=3)
    # Otsu自动阈值二值化
    _, binary = cv2.threshold(sobel_x, 0, 255,
                              cv2.THRESH_BINARY + cv2.THRESH_OTSU)
```

**原理**: 车牌区域因字符存在，垂直边缘特别丰富。

##### 方法三：矩形定位 (Canny)

```python
def rectangle_locate(self, image):
    # 双边滤波保边去噪
    blurred = cv2.bilateralFilter(gray, 11, 17, 17)
    # Canny边缘检测
    edges = cv2.Canny(blurred, 30, 200)
    # 筛选近似矩形轮廓
    approx = cv2.approxPolyDP(contour, 0.02 * peri, True)
    if 4 <= len(approx) <= 12:  # 允许一定不规则
        candidates.append(contour)
```

**原理**: 直接检测图像中的矩形边框。

#### 2.2.3 候选筛选机制

对检测到的轮廓进行多重过滤：

| 过滤条件 | 参数 | 说明 |
|----------|------|------|
| 长宽比 | 2.0 ~ 4.0 | 中国车牌标准约3:1 |
| 面积比 | 0.1% ~ 8% | 相对于图像面积 |
| 矩形度 | ≥ 0.5 | 轮廓面积/外接矩形面积 |
| 边缘密度 | ≥ 0.06 | 内部应有字符边缘 |

#### 2.2.4 评分机制

```python
# 长宽比评分：越接近3:1越高
ratio_score = 1.0 - abs(aspect_ratio - 3.0) / 2.0
# 矩形度评分
rect_score = rectangularity
# 边缘密度评分
edge_score = edge_density
# 综合评分
score = ratio_score * 0.6 + rect_score * 0.4
final_score = score * 0.7 + edge_score * 0.3
```

#### 2.2.6 形态学处理

```python
def morphology_process(self, binary_image, kernel_size):
    # 闭运算：连接断开的区域
    closed = cv2.morphologyEx(binary, cv2.MORPH_CLOSE, kernel)
    # 开运算：去除小噪点
    opened = cv2.morphologyEx(closed, cv2.MORPH_OPEN, kernel)
```

**核大小配置**:
- 颜色定位: (17, 5) - 连接被字符分割的区域
- 边缘定位: (15, 5) - 保持边缘细节

#### 2.2.7 调用示例

```python

# 方式二：类调用

# 提取车牌区域

    plate_img = locator.extract_plate_region(image, rect, box)
```

